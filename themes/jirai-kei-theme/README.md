# Jirai Kei · Windose Dark

Pink Win98-style window chrome on dark jirai-kei panels, with pixel controls, lace borders, hearts and photo-corner decorations. Fully self-contained: fonts, icons and decorations are embedded, no remote assets.

Embedded pixel icons (Lucide/Feather, ISC/MIT) and font subsets (Fusion Pixel, Silkscreen, SIL OFL 1.1) keep their notices at the top of `theme.css`.
